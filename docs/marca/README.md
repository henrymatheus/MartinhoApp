Guia completo (cores, tipografia, tom de voz, componentes): https://claude.ai/artifact/DBGPR6HYLjxbw6tM4uJdz7

| Arquivo | Uso |
|---|---|
| `martinho-simbolo.svg` | Símbolo circular: avatar, favicon, espaços pequenos (mínimo 24px) |
| `martinho-icone-app.svg` | Ícone quadrado do PWA (512px) |

| `martinho-logotipo-azul.svg` / `-branco.svg` | Só o nome, com sublinhado dourado |

## Resumo

- **Cores:** azul-marinho `#0E2240`, azul de ação `#1B3A6B`, branco e dourado `#C29A45`. O dourado é detalhe, nunca fundo grande nem texto sobre branco.
- **Fontes (Google Fonts):** Bodoni Moda 700 (tamanho óptico 11) para a marca e títulos; Figtree 400–600 para a interface.
- **Símbolo:** um M cortado por uma lâmina dourada, referência à capa que São Martinho cortou com a espada e ao corte do barbeiro.
